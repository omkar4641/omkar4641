### 1. LogicLadder AI — AI-Powered DSA Learning Platform

A Java-based, console-driven learning platform designed to help learners build consistent DSA practice habits through personalized tasks, progress tracking, AI-assisted learning, and coding contests.

**Key Features**

- **Account Creation & Login:** User authentication with Argon2id password hashing.
- **Personalized Onboarding:** Select a DSA learning level and configure daily study capacity.
- **Today's DSA Tasks:** View allocated problems, difficulty, estimated solving time, and problem links; mark completed questions.
- **DSA Progress Dashboard:** Track current-level completion, remaining questions, and difficulty-wise progress.
- **AI DSA Mentor:** Get problem explanations, detailed dry runs, brute-force approaches, and optimal approaches.
- **AI-Generated DSA Contest:** Generate a three-question contest using the learner's current level and recorded solving profile.

**Tech Stack:** Java, Maven, JDBC, MySQL, Groq API, Jackson, Argon2id
